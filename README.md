# Vinkora Plugins

Plugins de WordPress de Vinkora — https://vinkora.net

## CTC Vinkora

Boton de WhatsApp para WordPress: pestanas de configuracion, varios estilos de boton, ventana de saludo + formulario, multi-agente, reglas de visibilidad y rastreo (UTMs + GA4 + Google Tag Manager + Meta Pixel). Universal, autonomo, sin dependencias externas.

Los releases de este plugin usan la etiqueta `ctc-vinkora-*` (ej. `ctc-vinkora-2.0.1`). El plugin se auto-actualiza desde esos releases.

Instalacion: descarga el zip del ultimo release y subelo en WordPress -> Plugins -> Anadir nuevo -> Subir plugin.
